# WozterCode Desktop

A free, cross-platform code editor built on Code - OSS.

WozterCode Desktop is designed for developers, with an extensible editing experience and support for extensions through Open VSX.

## Downloads

**Current stable release:** [WozterCode 2.0.1](https://github.com/WozterCode/woztercode-download/releases/tag/v2.0.1)

### Supported Platforms

- **Windows x64:** [User installer](https://github.com/WozterCode/woztercode-download/releases/download/v2.0.1/WozterCodeSetup-x64-2.0.1.exe)
- **Linux x64:** [Debian package (`.deb`)](https://github.com/WozterCode/woztercode-download/releases/download/v2.0.1/woztercode-linux-x64.deb), [RPM package (`.rpm`)](https://github.com/WozterCode/woztercode-download/releases/download/v2.0.1/woztercode-linux-x64.rpm), [AppImage](https://github.com/WozterCode/woztercode-download/releases/download/v2.0.1/woztercode-linux-x64.AppImage)
- **macOS:** Planned

[Download SHA-256 checksums](https://github.com/WozterCode/woztercode-download/releases/download/v2.0.1/SHA256SUMS.txt) for the Windows installer and Linux packages.
