# WozterCode Desktop

**A free, cross-platform code editor built on Code - OSS.**

WozterCode Desktop is a desktop code editor designed for developers, with an extensible editing experience and support for extensions through Open VSX.

## Downloads

Official installers and application packages are available through [GitHub Releases](https://github.com/WozterCode/woztercode-download/releases).

**Current release:** [WozterCode 2.0.1](https://github.com/WozterCode/woztercode-download/releases/tag/v2.0.1).

### Supported Platforms

- **Windows x64:** [Download the 2.0.1 installer](https://github.com/WozterCode/woztercode-download/releases/download/v2.0.1/WozterCodeSetup-x64-2.0.1.exe)
- **Linux x64:** Debian package (`.deb`), RPM package (`.rpm`), AppImage, and portable archive (`.tar.gz`) are available in the [2.0.0 release](https://github.com/WozterCode/woztercode-download/releases/tag/v2.0.0).
- **macOS:** Planned

The 2.0.1 release provides the Windows x64 installer. Linux packages from 2.0.0 remain available while updated Linux builds are prepared.

## Free Software Distribution

WozterCode Desktop is provided free of charge.

This repository is intended exclusively for official application downloads, release notes, and distribution metadata. It does not contain the WozterCode Desktop application source code.

WozterCode includes components derived from Code - OSS and other third-party open-source projects. Their respective licenses and notices remain applicable.

GitHub's v2.0.1 source archives are generated from an empty release snapshot, so they contain no application source code. Download the Windows installer or Linux package from the release assets above.
