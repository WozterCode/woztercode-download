# WozterCode Desktop

**A free, cross-platform code editor built on Code - OSS.**

WozterCode Desktop is a desktop code editor designed for developers, with an extensible editing experience and support for extensions through Open VSX.

## Downloads

Official installers and application packages will be available through [GitHub Releases](https://github.com/WozterCode/woztercode-download/releases).
